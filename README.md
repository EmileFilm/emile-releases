# Émile releases

The released builds of [Émile](https://emilefilm.com), the video editor for Mac built for AI.

This repository holds no source code. Each [release](https://github.com/EmileFilm/emile-releases/releases) carries:

- the `.dmg` to download and install,
- the signed app archive and `latest.json` the app's own updater reads (every update is checked against Émile's signing key before it is installed).

Émile itself is proprietary software. The free packs it uses (filters, transitions, sounds, instruments) are open: [EmileFilm/emile-packs](https://github.com/EmileFilm/emile-packs).

There is no release yet: Émile is in development.
